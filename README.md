# Salima

麒仙老師（Salima）講師介紹網頁 —— 可愛科技風格的單頁靜態網站。

- `index.html`：網頁本體（HTML / CSS / JS 皆內嵌）
- `assets/avatar.jpg`：頭像插畫

## 用 GitHub Pages 上線

1. 將此分支合併到 `main`。
2. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約 1 分鐘後即可在 `https://<你的帳號>.github.io/Salima/` 看到網頁。
